# Riya Chitnis — ADHD Coach Website

A modern, responsive, Apple-inspired personal branding and coaching website for **Riya Chitnis**, a certified ADHD and Executive Function Coach based in **Abu Dhabi, UAE**.

---

## ✨ Design & Features

- **Apple-Inspired Aesthetic**: Minimalist layout, SF Pro typography hierarchy, frosted glass navigation (`backdrop-filter: blur`), refined bento grid cards, subtle glowing gradients, and pill-shaped action buttons.
- **Hero & Personal Branding**: Spotlights Riya's photo (`riyachitnis.JPG`), key credentials, and an Abu Dhabi studio badge.
- **Interactive 60-Second ADHD Clarity Check**: 4-step self-assessment with dynamic score calculation, instant feedback, and tailored coaching recommendations.
- **Neurodiversity-Affirming Comparison**: Clear side-by-side analysis highlighting why conventional productivity advice fails ADHD brains and how Riya's tailored architecture succeeds.
- **Interactive Bento Grid**: 6 core coaching pillars covering Dopamine Architecture, Time Blindness, Emotional Regulation & RSD, Executive Function for Professionals, Sensory Design, and Unmasking.
- **Pricing & Currency Switcher**: 3 coaching packages with real-time toggle between **AED (UAE Dirhams)** and **USD ($)**.
- **Interactive 60-Second Focus Reset Tool**: Visual breathing pacer inspired by Apple Watch Mindfulness for immediate nervous system grounding.
- **Abu Dhabi & UAE Location Hub**: Highlights in-person session availability across Abu Dhabi (Al Maryah Island, Saadiyat, Downtown) and Dubai, plus global virtual video consultations.
- **Consultation Booking Modal & WhatsApp Direct Link**: Sleek modal for scheduling clarity calls with WhatsApp integration and confirmation toast.
- **Apple Dark / Light Theme Toggle**: Seamless mode switcher with local storage persistence.

---

## 🚀 Deployment & Local Preview

This project is built with vanilla **HTML5, CSS3, and modern JavaScript**, with zero dependencies or build steps required.

### Local Preview:
Open `index.html` directly in any web browser, or serve it locally:

```bash
# Using Python
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

### GitHub Pages:
Since this repository is configured for GitHub Pages (`riyachitnis.github.io`), simply commit and push changes to the `main` branch. GitHub Pages will host the site live automatically.
